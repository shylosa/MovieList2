- [x] На картках фільмів тип не дублюється; серіали мають компактну позначку «TV».
- [x] Рейтинг картки бібліотеки розташований праворуч від року й типу, без окремого рядка.
- [x] Кожна картка бібліотеки показує жанри; довгий перелік має підказку, а для відсутніх жанрів є явний підпис.
- [x] Очищення пошуку й сортування не стирають знайдені варіанти TMDB, поки вибраний файл лишається у списку.

- [x] Чекбокс «Вибрати всі» вибирає записи поточного списку; обсяг вибору пояснює підказка.
- [x] Панель вибраного запису показує постер із заглушкою, назву й метадані поруч.
- [x] Зберегти верхній заголовок Редактора; прибрати тільки заголовок таблиці та розмістити «Вибрати всі» біля фільтрів.
- [x] Редактор — перший пункт у блоці «Інструменти» сайдбару.
- [x] Посилання в програмі та локальній і мобільній вітринах не підкреслюються, зокрема при наведенні.
- [x] Одна пакетна кнопка «Уточнити й виправити» відкриває поля вибраних файлів; запуск виконується всередині панелі.
- [x] Око показує прев’ю розпізнаного запису з постером без додаткового API-запиту; клік відкриває повний перегляд.

- [x] Варіанти TMDB компактні; кнопки «Деталі» й «Обрати» розміщені праворуч.
- [x] Підпис файлу у панелі запису — «ФІЛЬМ» (для серіалу — «СЕРІАЛ»).
- [x] Пакетне уточнення: окремі тип і підказка для кожного вибраного чекбоксом файлу в одному вікні.

## Інтерфейс і поведінка

- [x] Компактна панель пошуку, фільтрів, сортування й кількості записів.
- [x] Список файлів і панель вибраного запису; адаптивна панель у вузькому вікні.
- [x] Вибір кількох записів звичайними чекбоксами, видима кількість вибраних і контекстні масові дії.
- [x] Статус та перегляд у рядку показані значками з підказками й доступними назвами; меню з трьома крапками немає.
- [x] Тип, текстова підказка і пошук до п’яти варіантів TMDB у панелі запису. Деталі кандидата завантажуються тільки на явний запит.
- [x] Збережено переходи Бібліотека → фільм → Редактор, очищення пошуку, виправлення і видалення вибраних.

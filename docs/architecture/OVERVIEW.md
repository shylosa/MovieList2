# Архітектура MovieList

MovieList індексує локальні відеофайли в SQLite, отримує метадані TMDB і показує каталог у Wails. Інтерфейс передає дії через bindings до `App`. `App` координує підсистеми та повертає дані й події. [main.go](../../main.go), [frontend/src/main.js](../../frontend/src/main.js), [app.go](../../app.go)

| Підсистема | Вхід, напрям викликів і результат |
| --- | --- |
| Запуск | `main` завантажує `config.Load`, налаштовує логування, вбудовує `frontend/dist`, прив’язує `App` і реєструє `startup` / `shutdown`. `startup` ініціалізує SQLite, відновлює джерела та створює клієнти TMDB і AI. [main.go](../../main.go), [app.go](../../app.go#L142), [go.mod](../../go.mod) |
| Диск | `RunScan` → `getDiskFiles` → `Scanner.GetDiskFiles`. Абсолютні шляхи переходять до парсингу й розпізнавання, `Config.MediaIdentifier` формує стабільні ключі для SQLite. [app.go](../../app.go#L727), [scanner.go](../../internal/scanner/scanner.go), [media_paths.go](../../internal/config/media_paths.go) |
| Визначення твору | `runTMDBScan` → `ParseFilename` → `FetchFromParsed`. Для невирішених записів `processScanResults` перевіряє AI-кеш, а `processGeminiQueue` отримує гіпотезу AI й окремо перевіряє її через TMDB. Порядок залежить від режиму. [app.go](../../app.go#L977), [RECOGNITION.md](RECOGNITION.md) |
| AI | `App.modelContext` передає вибір моделей до спільного `ai.Client`. Gemini працює через `google.golang.org/genai`, резервні Groq та legacy xAI Grok мають окремі HTTP-клієнти й конфігурацію. Локалізація користується тим самим каскадом після встановлення identity. [app_models.go](../../app_models.go), [gemini.go](../../internal/ai/gemini.go), [groq.go](../../internal/ai/groq.go), [grok.go](../../internal/ai/grok.go) |
| Каталог та редактор | `GetMovies` читає SQLite й обчислює `file_label` / `file_path`. UI викликає уточнення, підтвердження й Repair за `filename`. `SaveMoviesBatch` зберігає записи, `app_state` зберігає налаштування. [app.go](../../app.go#L243), [app_repair.go](../../app_repair.go), [storage.go](../../internal/storage/storage.go), [WAILS_UI_CONTRACTS.md](WAILS_UI_CONTRACTS.md) |
| Вивід | `App` читає каталог для `web.Generate` (локальна вітрина або мобільний `index.html`) і `sheets.Client.SyncMovies`. `SyncToGitHub` запускає зовнішній Git за явною дією. [app.go](../../app.go#L403), [generator.go](../../internal/web/generator.go), [sheets.go](../../internal/sheets/sheets.go) |
| Службові дані | `app_env.go` працює з вибраним `Config.EnvPath`. `internal/utils` надає JSONL-лог, trace ID, мовні й шляхові функції. `internal/version` вбудовує `VERSION` для UI, логів і вітрин. [app_env.go](../../app_env.go), [logger.go](../../internal/utils/logger.go), [lang.go](../../internal/utils/lang.go), [path_display.go](../../internal/utils/path_display.go), [version.go](../../internal/version/version.go) |

Для змін життєвого циклу починайте з `RunScan`, `FixSelected`, `finalizeScan`, `shutdown` і тестів з ін’єкцією диска, Git та подій. `app.go` зосереджує ці entry points, черги, ручний пошук та експорт. Налаштування моделей, `.env`, джерела, локалізація, діагностика й Repair мають окремі файли root package. `main.js` з’єднує панелі, Bridge і події, а допоміжні модулі підключаються звичайними ES imports через Vite. [app.go](../../app.go), [app_lifecycle_github_test.go](../../app_lifecycle_github_test.go), [app_recognition_log.go](../../app_recognition_log.go), [app_localization.go](../../app_localization.go), [frontend/src/main.js](../../frontend/src/main.js), [frontend/package.json](../../frontend/package.json)

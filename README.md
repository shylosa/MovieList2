# 🍿 MovieList 2.0 - Менеджер локальної медіатеки

**MovieList 2.0** — це повністю переписаний на **Go (Golang) та Wails** десктопний додаток для автоматизації вашої локальної колекції фільмів. Він перетворює хаотичну папку з відеофайлами на структурований кінокаталог з постерами, описами та хмарною синхронізацією.

Завдяки переходу з Python на Go, програма тепер працює блискавично, не потребує встановлення інтерпретаторів, компілюється в один `.exe` файл і має сучасний, чуйний веб-інтерфейс.

## ✨ Головні інновації версії 2.0
* **⚡ Блискавична швидкість:** Написаний на Go, додаток використовує конкурентність та компілюється в один бінарний файл. Жодних `pip install` чи віртуальних середовищ для кінцевого користувача.
* **🧠 Єдиний детермінований пайплайн (go-ptn):** Надійна токенізація імен файлів замість крихких регулярних виразів. Надійно розпізнає назви, роки, якість (1080p, WEB-DL) та реліз-групи.
* **🛡️ "Бетонна стіна" валідації:** Розумна перевірка років (з допуском ±1 рік) та fuzzy-scoring відкидають хибні результати від TMDB, залишаючи базу чистою.
* **🤖 ШІ-асистент (Gemini):** Якщо файл має надто "піратську" або специфічну назву, в гру вступає Google Gemini для семантичного розбору та пошуку правильної англійської назви.
* **🖥️ Сучасний UI (Wails + JS):** Нативний десктопний додаток зі зручними вкладками "Огляд", "Редактор" та "Налаштування".
* **✏️ Розумний Редактор (з кешуванням):** Можливість в один клік "вилікувати" проблемні файли, просто вставивши TMDB ID. Інтерфейс підтримує масове редагування та розумне оновлення DOM.

## 📦 Можливості, що залишились і стали кращими
* **🇺🇦 UA локалізація:** Пріоритет українських даних з TMDB.
* **🎨 Офлайн HTML-вітрина:** Генерація статичного `index.html` (SPA) з вашою колекцією для перегляду каталогу без запуску основного додатка чи інтернету.
* **☁️ Синхронізація з Google Sheets:** Експорт колекції в хмару для доступу з телефону.
* **💾 Локальна БД SQLite:** Надійне зберігання всіх метаданих та кешування постерів на диску.

## 🚀 Встановлення та запуск

### Варіант А: Запуск готового додатка (Для користувачів)
1. Завантажте скомпільований файл `movielist-app.exe` (з вкладки Releases).
2. Поруч із файлом створіть файл `.env` із вашими ключами (див. шаблон нижче).
3. (Опціонально) Покладіть `credentials.json` у ту ж папку.
4. Запустіть `.exe`.

### Варіант Б: Збірка з вихідного коду (Для розробників)
**1. Клонуйте репозиторій:**
```bash
git clone [https://github.com/shylosa/movielist2.git](https://github.com/shylosa/movielist2.git)
cd movielist2
```
**2. Налаштуйте файл оточення:**
Створіть файл .env у корені проєкту:
```bash
TMDB_API_KEY=твій_ключ_tmdb
GEMINI_API_KEY=твій_ключ_gemini
MEDIA_FOLDER_PATH=D:\Films
EXCLUDE_FOLDERS=System Volume Information, $RECYCLE.BIN
GOOGLE_SHEET_WORKSHEET_NAME=movies
```

**3. Запуск у режимі розробки (Live Reload):**
```bash
wails dev
```

**4. Компіляція готового .exe файлу:**
```bash
wails build
```

Скомпільований файл з'явиться у папці build/bin/.

🎮 Керування та інтерфейс
Інтерфейс розділений на зручні вкладки:

📊 Огляд: Дашборд зі статистикою. Кнопки запуску сканування, створення HTML-вітрини та хмарної синхронізації.

✏️ Редактор: Потужна таблиця всіх файлів. Дозволяє шукати, масово видаляти та виправляти нерозпізнані файли. Просто вставте TMDB ID у поле підказки, виділіть чекбокси і натисніть "Виправити вибрані".

📜 Логи: Перегляд логів розпізнавання прямо у додатку.

🌐 Відкрити вітрину / Таблицю: Швидкі посилання для відкриття згенерованого каталогу або Google Sheets у вашому браузері.

📁 Архітектура проєкту
```bash
movielist2/
├── app.go              # Головний контролер життєвого циклу (зв'язок Go ↔ JS)
├── main.go             # Точка входу Wails
├── wails.json          # Конфігурація проєкту Wails
├── frontend/           # Vanilla JS, HTML, CSS (Vite)
│   └── src/main.js     # Фронтенд-логіка (UI, кеш, виклики Go-методів)
└── internal/
    ├── ai/             # gemini.go (інтеграція з Google Gemini API)
    ├── config/         # Завантаження .env конфігурацій
    ├── scanner/        # Обхід директорій, фільтрація відеофайлів
    ├── sheets/         # Експорт даних у Google Sheets
    ├── storage/        # Локальна SQLite база (movies.db)
    ├── tmdb/           # Парсинг імен (go-ptn), API клієнт, завантаження постерів
    └── web/            # generator.go (Генерація статичного index.html каталогу)
```
